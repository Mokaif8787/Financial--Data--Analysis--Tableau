# Financial Data Analysis Dashboard — Tableau

## Project Overview
An interactive financial dashboard developed using Tableau to analyze financial performance and visualize key business metrics.

## Key Metrics
- Gross Profit
- EBITDA
- Operating Profit
- PBIT
- Net Profit

## Dashboard Features
- Profit and Loss analysis
- Sales and marketing expense visualization
- Region, country, quarter and month filters
- Financial performance comparisons

## Tools Used
- Tableau Desktop
- Data Visualization
- Financial Data Analysis
